# Week Ahead — a Home Screens plugin

The coming week at a glance for Sunday planning: each day's weather, everyone's events colour-coded by person, the school cycle day and the dinner planned.

Install: Home Screens editor → Plugins → Install from URL…

```
https://github.com/tweetyboopdev2022-code/home-screens-week-ahead/releases/latest/download/week-ahead.tgz
```

Build: `npm install && npm run build`
